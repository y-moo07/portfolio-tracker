# Portfolio Tracker

A command-line portfolio tracker built in C++ that calculates current 
value and profit/loss across multiple stock positions using real ticker 
symbols (AAPL, TSLA, NVDA, SPY).

Demonstrates: object-oriented programming, encapsulation, vectors of 
objects, parallel vector iteration, and aggregate financial calculations.

To compile: clang++ portfolio_tracker.cpp -o portfolio_tracker

To run: ./portfolio_tracker
